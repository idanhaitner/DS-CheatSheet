9 · Cram Recap

You already know this — one dense pass before the exam. Deep links only when you blank.

How to use: scan top→bottom once. Red boxes = 2026A-style traps / “write the definition”. Need a full proof? click the § links. Quiz: §8.

0 · Quote these cold

  • Safe edge: \(A\subseteq\) some MST; \((u,v)\) safe for \(A\) iff \(A\cup\{(u,v)\}\subseteq\) some MST. → §6.5
  • Cut property: \(A\subseteq\) MST, cut respects \(A\), light edge across cut ⇒ safe. Exchange on unique cycle.
  • Prim safe: \(S=\) extracted verts; light edge = \((u.\pi,u)\). Kruskal: \(S=\) component of \(u\).
  • Accounting invariant: every prefix \(\sum c_i\le\sum\hat c_i\) (bank never negative mid-sequence).
  • Universal \(\mathcal H\): \(\Pr[h(x)=h(y)]\le 1/m\) for \(x\neq y\). Family \(f_{a,b}\) with \(a\neq 0\).
  • AVL: \(|h_L-h_R|\le 1\), \(h(\mathrm{NULL})=-1\). Height \(n_k=n_{k-1}+n_{k-2}+1=F_{k+3}-1\Rightarrow\le 1.44\log n\).
  • B-tree \(t\): non-root keys \(\in[t{-}1,\,2t{-}1]\); all leaves same depth; \(h\le\log_t\frac{n+1}{2}\).
  • Complete BT: perfect, or perfect minus consecutive right-to-left leaves.

2 · Foundations

Asymptotics

  • \(O\) upper, \(\Omega\) lower, \(\Theta=O\cap\Omega\).
  • Not every pair comparable (even/odd counterex).
  • \(f=O(g)\Leftrightarrow g=\Omega(f)\). \(\Theta\) symmetric.
  • Poly \(b_kn^k+\cdots=\Theta(n^k)\).

Master / trees

  • \(aT(n/b)+f\): compare \(f\) to \(n^{\log_b a}\) with \(\varepsilon\)-gap.
  • Case 3 needs regularity \(af(n/b)\le cf\), \(c<1\).
  • Fails: \(n/\log n\) (no poly gap) → tree.
  • \(T(n/3)+T(2n/3)+n=\Theta(n\log n)\).

Probability

  • Linearity: always (no independence).
  • Indicator: \(E[X_A]=\Pr[A]\).
  • Geo(\(p\)): \(E=1/p\). Bin: \(np\).
  • Union bound: no independence.

3 · Sorting & Select

  • Ω(n log n): ≥n! leaves; binary ≤2ʰ leaves; \(n!\ge(n/2)^{n/2}\). → proof
  • Stable: Counting (downto), Merge, Radix (needs stable digit). Quick/Heap: no.
  • Radix: LSD; after \(i\) digits sorted; base \(b=n\) when \(u>n\) → \(\Theta(n\log u/\log n)\); \(u\le n^c\Rightarrow\Theta(n)\).
  • Bucket avg: \(E[n_0^2]=2-1/n\) via indicators → Θ(n). Deterministic; avg ≠ worst-case expected.
  • Partition: zones ≤pivot / >pivot / unexamined / pivot. Quick worst: always (n−1,0).
  • MoM: ≥\(\frac3{10}n-6\) on each side of pivot; recurse ≤\(\frac7{10}n+6\).

4 · Trees

BST / AVL

  • Delete 2 kids → successor (no left child).
  • Succ: right→min, else climb while right-child.
  • Case by tallest grandchild; delete tie → LL/RR.
  • Rotate ≠ undone by re-insert (2026A).

B-tree

  • Split: median up; two × (t−1) keys.
  • 1-pass: fix full/thin before enter.
  • 2-pass: find then fix path suffix.
  • Delete internal: replace by successor (lecture ≠ CLRS).

OST

  • size on node; Select/Rank \(O(\log n)\).
  • vs Indexable SL: expected OK → width; worst-case → OST.

5 · Heap & Compression

  • BuildHeap Θ(n): ≤n/2ʰ⁺¹ nodes height \(h\); \(\sum h/2^h=2\). → §4.1
  • Heap ≠ sorted (2026A). 3rd-largest can sit depth 1 or 2.
  • Huffman: sibling lemma → induct on |C|; cost(T)=cost(T′)+z.freq. Min bits = skewed; max = balanced.
  • LZ78: phrase = longest prior block + 1 char → (j,c). Min phrases Ω(√n) since lengths ≤1..p. Bits Θ(√n log n).

6 · Skip list & Hash

Skip list

  • Promote w.p. 1/2; \(E[|S_i|]=n/2^i\); space ~2n.
  • \(E[h]\le\log n+2\) (split sum).
  • Backward search: \(E\le 2\log n+5\).
  • Delete (ptr): \(E[H]=1\Rightarrow\Theta(1)\).

Hash

  • α=n/m; keep α∈[1/4,1] with rehash.
  • Universal → \(E[\text{list}]\le1+\alpha\).
  • Max bin \(\Theta(\log n/\log\log n)\) whp.
  • LP delete: tombstone or reinsert run.
  • Bloom: no FN; FP \((1-e^{-kn/m})^k\); no delete.

7 · Graphs

BFS / DFS

  • BFS: layers = δ; unweighted SP.
  • Parenthesis: nest ⟺ descendant.
  • White-path: white path at d[u] ⟺ desc.
  • Cycle ⟺ back edge (digraph).
  • Topo: decreasing f; prove f[v]<f[u].
  • Undirected DFS: only tree+back.

MST / SSSP

  • GenericMST: always add safe edge.
  • e in some MST? BFS on lighter edges.
  • e in every MST? BFS on ≤w without e.
  • Dijkstra: no neg edges.
  • BF: |V|−1 relax; extra pass = neg cycle.
2026A Prim variant: if \(Q=\{r\}\) only — Insert new verts, DecreaseKey if already in Q.

8 · Amortized & UF

  • Only Aggregate + Accounting in course (no Φ).
  • Counter: bit \(i\) flips \(n/2^i\); total <2n. Accounting: charge $2; $1 on every 1-bit. → §7.1
  • Multipop: Push charge 2; Pop/Multi 0. Each elem $1.
  • Rehash: Insert charge $3; shrink at n=m/4 → m/2.
  • Weighted union: pointer updates ≤log n per elem → \(O(m+n\log n)\).
  • Rank ≠ height: PC shortens height; rank is upper bound only.
  • B-tree amort: charge 3/2; credits on thin/full nodes; ≤(3/2)m structural ops.
  • BB[α]: rebuild highest unbalanced; α=1/3 charge \(4(h+1)\); ≥M/3 inserts fund rebuild.
  • Deamort rehash: over m/2 inserts do 3–4 copy steps; every Insert O(1) worst.

10 · Trap checklist

  • buildHeap is \(\Theta(n)\), not \(n\log n\). Heap order ≠ BST order ≠ sorted array.
  • Quicksort \(\Theta(n^2)\) on sorted with fixed pivot. Not stable.
  • Bucket worst \(n^2\); don’t claim worst-case linear.
  • Dijkstra fails with negative edges → BF.
  • BFS = fewest edges, not weighted SP.
  • Spanning tree ≠ MST. Light edge ≠ “any tree edge”.
  • Plain BST worst \(O(n)\). AVL insert ≤1 rot ≠ delete.
  • Skip Delete with width is \(E:O(\log n)\), not \(O(1)\).
  • Master without \(\varepsilon\)-gap fails. Prefer Θ when tight; name the theorem.
  • UF representative can change after Union — don’t cache across Unions.
  • Amortized ≠ average over inputs; sequence worst-case.
  • Potential method: not in lectures — don’t invent it.
